01 / PARADIGM & MOTIVATION

The model plans.
The Gym executes.

Multimodal large language models (MLLMs) increasingly act as embodied brains over extended interactions. Yet real-world assistance rarely unfolds in a single room or under complete upfront knowledge: agents must traverse connected indoor and outdoor spaces, gather distributed clues from landmarks and NPCs, adapt to revised instructions, and remember what they saw twenty steps earlier.

EmbodiedExploreGym encapsulates low-level spatial computation—including SAM2.1 target segmentation, eroded depth localization, and Unreal Engine NavMesh path execution—into a unified callable tool interface. By removing low-level continuous control noise, evaluation isolates high-level task understanding, active exploration, error recovery, and long-horizon memory.

I

Unified 3D Embodied Gym

15+ ego perception, SAM2+Depth visual approach, NavMesh routing, door traversal, and NPC dialogue tools on UnrealZoo (UE 5.7).

 II

EmbodiedExploreBench (307 Tasks)

12 task families spanning community districts, industrial yards, hospitals, and workplaces with multi-stage dependencies.

 III

Dual Whole-Task & Subtask Diagnostics

Deterministic pose/event checks paired with rubric-based LLM judges measuring both Success Rate (SR) and Subtask Completion Rate (SCR).

03 / ENVIRONMENT ARCHITECTURE

Closed-Loop Interaction in EmbodiedExploreGym

Built on UnrealZoo, Unreal Engine 5.7, and UnrealCV, the Gym couples ego RGB perception with 3D spatial grounding, scripted NPC dialogue, and hybrid deterministic + semantic trace evaluation.

Appendix F · Action Space

15 Callable Tools Across 6 Action Modules

Visual Target Grounding Pipeline

SAM2.1 Hiera-Large + Eroded Depth Localization

When an agent calls navigate_to_segmented_target(target, box), the executor waits for positional settling (≤1 cm over 10 s), segments the normalized box at 1024×1024 via SAM2.1, applies a 5×5 mask erosion, clusters radial depth samples across discontinuities > max(80 cm, 0.08 d), and projects the dominant surface median into world coordinates for UE NavMesh pathing.

2D Box [x0,y0,x1,y1] → SAM2.1 Mask + 5×5 Erosion → Depth Cluster Median x̂ → UE 5.7 NavMesh Path
Dual-Layer Trace Evaluation

Deterministic Spatial Checks + Rubric Judge

Every episode records full ego poses, timestamps, reached NPC identities, and tool outcomes. Deterministic rules verify spatial proximity, door crossings, station order, and actual recipient identity—preventing hallucinated self-claims—while Qwen3.8-Max evaluates factual completeness against hidden stage rubrics to score whole-task SR and subtask SCR.

Recorded Pose & Call Log → Deterministic Event/Order Gate → Stage Semantic Rubric → SR & SCR Verdicts

07 / OPEN-SOURCE EVALUATION SUITE

Evaluate Your Model in Three Commands

EmbodiedExploreGym ships with prebuilt UnrealZoo UE 5.7 Linux runtime integration, standalone SAM2.1 visual approach service, automatic shard resumption, and offline deterministic + semantic scoring.

  • Plug-and-play OpenAI-compatible API accepting image inputs and tool calls.
  • Fault-tolerant --resume & multi-GPU sharding across all 307 tasks.
  • Reproducible offline judge (eeb-evaluate & eeb-aggregate) for SR & SCR.
